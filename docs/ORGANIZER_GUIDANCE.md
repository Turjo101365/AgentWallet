# Organizer guidance on on-chain evidence

**Recorded:** 2026-10-16, by Samprity Haque.

**Question sent to the FinTechathon organizers (by email, paraphrased by the team):** whether publicly verifiable Base Sepolia testnet transaction hashes are acceptable, or whether mainnet transactions are mandatory.

**Organizers' reply (verbatim):**

> "There are no restrictions on on-chain transactions."

## How the team interprets it

- The reply places no restriction on which chain the on-chain transactions use. The team therefore treats publicly verifiable **public testnet** transactions as acceptable. This is a working assumption.
- The reply does **not** name testnets, Base Sepolia, Ethereum Sepolia, or any other network. We don't claim that it does.
- No real funds are used. All evidence transactions use free testnet ETH on a public EVM testnet. Each one is independently verifiable through a public block explorer and the chain's public RPC.

Keep the original email in the team's records. This file quotes only the reply text.
